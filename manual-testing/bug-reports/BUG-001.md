# BUG-001 — Регистрация проходит с несовпадающими паролями

**Окружение:**

- Windows 11
- Google Chrome
- тестовый стенд

**Предусловия:**

Открыта форма регистрации.

**Шаги воспроизведения:**

1. Ввести корректное имя.
2. Ввести корректный email.
3. Ввести пароль `Password1!`.
4. Ввести в поле подтверждения пароль `Password2!`.
5. Нажать «Зарегистрироваться».

**Фактический результат:**

Регистрация успешно завершается.

**Ожидаемый результат:**

Появляется сообщение «Пароли не совпадают».
Пользователь не создаётся.

**Severity:** Major  
**Priority:** High
