# Виды тестирования интернет-магазина
Сайт для тестирования: [SauceDemo](https://sauce-demo.myshopify.com/)

### Smoke Testing
Краткая проверка основных функций системы после сборки.
- [x] Главная страница сайта открывается
- [x] Пользователь может авторизоваться в системе
- [x] Каталог открывается и показывает список товаров
- [x] Поле "Поиск" находит товары
- [x] Пользователь может добавить товар в корзину
- [x] Можно перейти к оформлению заказа

### Functional Testing
Проверка основной функциональности, например, кнопки "Добавить в корзину":

- [x] Товар добавляется в корзину
- [x] Количество товара увеличивается
- [x] Товар отображается в корзине
- [x] После обновления страницы товар остается в корзине

### Regression
Проверяем, что новое изменение не сломало существующие функции.
Например, разработчик изменил корзину. После этого проверяем не только корзину, но и:
 - [x] каталог;
 - [x] карточку товара;
 - [x] авторизацию;
 - [x] промокод;
 - [x] оформление заказа;
 - [x] оплату;
 - [x] историю заказов.

REGRESSION: Корзина после изменения

- [x] Каталог открывается
- [x] Карточка товара открывается
- [x] Товар добавляется в корзину
- [x] В корзине отображается правильное название товара
- [x] В корзине отображается правильная цена товара
- [x] Количество товара можно увеличить
- [x] Количество товара можно уменьшить
- [x] Общая сумма пересчитывается после изменения количества
- [x] Товар можно удалить из корзины
- [x] После удаления товара пересчитывается общая сумма
- [x] Пустая корзина отображается корректно
- [x] Товар сохраняется в корзине после обновления страницы
- [x] Можно перейти из корзины к оформлению заказа
- [x] Промокод применяется корректно
- [x] Нельзя оформить заказ с пустой корзиной

### Retest
Повторная проверка конкретно исправленного бага.
Например, был найден баг с оплатой заказа.
- [x] Открыть сайт
- [x] Авторизоваться
- [x] Открыть каталог
- [x] Добавить товар в корзину
- [x] Перейти в корзину
- [x] Нажать «Оформить заказ»
- [x] Проверить, что открылась страница оформления заказа
- [x] Заполнить адрес доставки
- [x] Нажать «Подтвердить заказ»
- [x] Проверить, что заказ успешно создан
