Сайт для тестирования: [SauceDemo](https://sauce-demo.myshopify.com/)

### Чек-листы по SMOKE-тестированию
 Проверить, что сайт открывается
 Пользователь может авторизоваться
 Каталог открывается
 Пользователь может добавить товар в корзину
 Можно перейти к оформлению заказа

### Чек-листы по функциональному тестированию
Проверка функциональности кнопки "Добавить в корзину":
 Товар добавляется
 Количество товара увеличивается
 Товар появляется в корзине
 после обновления страницы товар остается

### Чек-листы по регрессионному тестированию
Проверяем, что новое изменение не сломало существующие функции.

Например, разработчик изменил корзину. После этого проверяем не только корзину, но и:
    каталог;
    карточку товара;
    авторизацию;
    промокод;
    оформление заказа;
    оплату;
    историю заказов.

### Чек-листы по Retest
Retest — повторная проверка конкретного исправленного бага.

Пример:

Был баг: при неверном пароле не показывалось сообщение.
Разработчик сообщил, что исправил проблему.
Вы повторяете те же шаги.
Проверяете, появилось ли сообщение.
Если проблема исчезла — закрываете баг.
Если проблема осталась — возвращаете баг в работу.
